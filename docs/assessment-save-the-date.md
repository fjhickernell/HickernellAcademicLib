# Assessment save-the-date workflow

Use this workflow when one or more quiz, test, or final-examination dates are
established before coverage or other assessment details are final. A
save-the-date is a coordinated course update, not merely a Canvas
announcement.

## Required updates

1. Audit the course website, Canvas, calendar, and existing announcements for
   the assessment before creating anything. Resume valid partial work and
   avoid duplicate items.
2. Resolve each assessment's sequential name from the authoritative assessment
   page, such as **Quiz 3** or **Test 2**.
3. Update both the course Schedule and the authoritative quizzes/tests page in
   the same change. Put the assessment name in the event column and write
   **Coverage TBD** in the materials or coverage column until coverage is
   finalized.
4. Create or update the Canvas grade item using the course's established
   assignment group, point value, submission type, audience, and class-end due
   time. Paper assessments normally use **On Paper** submission.
5. Modify only the matching occurrence on the instructor's work calendar,
   preserving its date, time, room, named time zone, and calendar account. Use
   a title such as **Quiz 3 in MATHxxx** or **Test 2 in MATHxxx**.
6. Post a course-wide Canvas announcement titled **Save the date: ...** for one
   assessment or **Save the dates: ...** for several. State the dates, location
   when established, and that coverage is TBD. Include other settled logistics
   without guessing unresolved details.
7. Defer the deck title-slide notice until coverage identifies the latest deck
   included in the assessment.
8. Render and verify the affected website pages, re-open the Canvas item and
   announcement, verify the calendar occurrence, and record durable Canvas IDs
   and completion state in the course metadata and handoff files.

If the final examination is known to be cumulative, say so consistently on
the assessment page, Schedule, and announcement. When appropriate, state that
the date, time, and location will be posted when scheduled by the Registrar,
and identify any established emphasis such as material not covered by earlier
tests.

## Publication boundary

Do not link an announcement to website changes until those changes are live.
If the save-the-date announcement must be posted before a repository
Checkpoint and deployment, make it self-contained and publish the website
updates at the next authorized Checkpoint.

Course-specific assessment rules remain in the consumer repository, including
permitted materials, duration, point values, page names, Canvas groups, and
final-examination format.
